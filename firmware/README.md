# Firmware

Custom firmware for the [DIY Flipper-style Multitool](../README.md) (ESP32-S3).

> **Status: not started.** This page collects what the firmware needs to know about the board, so it is ready when work begins. It is **not** compatible with the official Flipper Zero firmware.

## Target hardware

- **MCU:** ESP32-S3-WROOM-1-N16R2: 16 MB flash, 2 MB quad PSRAM, Wi-Fi and Bluetooth LE.
- **USB:** native USB on GPIO19/20 (USB-C). It is used for flashing, the serial console and USB HID; there is no separate USB-to-serial chip.
- **Shared buses:**
  - **SPI:** SCK IO12, MOSI IO11, MISO IO13, shared by the OLED, the microSD card and the CC1101 (one CS line each).
  - **I2C:** SDA IO1, SCL IO2, shared by the PN532 and the PCF8574 button expander.

## Peripherals

| Peripheral | Chip | Connection | Notes |
|---|---|---|---|
| Display | SH1106 128x64 OLED | SPI, CS IO10, D/C IO14, RST IO21 | |
| microSD | — | SPI, CS IO9 | Card detect on PCF8574 P7 |
| Sub-GHz | CC1101 (EBYTE E07-M1101D) | SPI, CS IO8, GDO0 IO7, GDO2 IO6 | One band per module |
| NFC | PN532 | I2C (address 0x24), IRQ IO4 | No reset line; module set to I2C mode |
| Buttons | PCF8574T | I2C (address 0x20), INT IO41 | P0 Up, P1 Down, P2 Left, P3 Right, P4 OK, P5 Back |
| Charge status | MCP73832 | PCF8574 P6 | |
| Battery voltage | — | IO5 (ADC1) | Reads VBAT/2 |
| IR transmit | 940 nm LED on N-FET | IO38 | |
| IR receive | TSOP38238 | IO39 | 38 kHz demodulated output |
| iButton | — | IO40 | 1-Wire, 2.2 k pull-up on the board |
| RFID 125 kHz | Discrete front end | Carrier IO15, modulation IO16, data IO17 | Experimental; needs custom code |
| RGB LED | SK6812 | IO48 | |
| Buzzer | Passive buzzer | IO42 | Tone generated by PWM |
| Vibration motor | — | IO47 | |
| Header UART | — | TX IO43, RX IO44 | |

The [ESP32-S3 pin map](../hardware/README.md#esp32-s3-pin-map) in the hardware README is the reference; if the two ever disagree, the hardware README wins.

**Strapping pins:** GPIO0 is the BOOT button. GPIO3, GPIO45 and GPIO46 go to the GPIO header; nothing connected there should pull them at reset, and GPIO45 must stay low.

## Flashing

1. Connect the board over USB-C.
2. If the board does not show up as a serial port (for example on the first flash), enter download mode: hold **BOOT**, press and release **RESET**, then release **BOOT**.
3. Flash with the tool of the chosen framework (for example `esptool`, ESP-IDF or PlatformIO).

## Possible starting point

[Bruce](https://github.com/BruceDevices/firmware) is an open-source ESP32 firmware (PlatformIO, AGPL-3.0) that already supports the CC1101, the PN532, IR and microSD cards. It could be adapted to this board. Two parts would need custom code in any case: the buttons on the PCF8574 expander and the discrete 125 kHz RFID front end. Code based on Bruce has to stay under the AGPL-3.0 license.
